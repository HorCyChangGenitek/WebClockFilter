# Web Clock Filter

A Chrome extension that allows or blocks specific websites based on time schedule, blacklist or whitelist. Features:

- Configure blacklist and whitelist.
- Modes: allow all except blacklist, block all except whitelist, or block blacklist only during scheduled times.
- Schedule supports selecting days of the week and multiple time ranges in 5 minute increments.
- Temporary unlock function allows access for 30 minutes up to 16 hours.

To use, load the extension in Chrome by enabling developer mode and selecting "Load unpacked".
